# Wan I2V スマホ動画生成アプリ（自分専用）

RunPod Serverless + Wan 2.2 Image-to-Video（I2V：画像から動画）で、
スマホだけを使って動画を生成するプロジェクトです。
デスクトップ PC は使いません。重い処理はすべて RunPod の GPU 側で行います。

> 用途は「成人向け（エッチな）動画を自分専用に作る」ことです。公開・配布はしません。
> そのため、ストア審査・他ユーザー向け課金・会員登録は作りません。
> 未成年や、同意のない実在人物の性的コンテンツは生成できないよう、
> アプリ側に簡易ガードを入れています（後述）。

### 検証で分かったクセ（重要）

- **解像度が2倍になる**: ワークフローに 832×480 を渡すと 1664×960 が返る。
  アプリとテストでは **半分のサイズ（416×240）を渡して 832×480 を得る** 方式で解決済み。
- **フレーム数は 4n+1**（49 / 81 / 121…）で指定する。秒数 × fps から換算する。
- **fps は2つの意味がある**: CreateVideo の fps は再生速度の指定（生成コスト不変）。
  動きの量自体を増やすのはフレーム数のほう（コスト増）。
- **キューの待ち時間は課金されない**。課金はワーカーが実行している時間だけ。
  EU-CZ-1 の RTX 3090 は在庫が不安定で、空き待ちが長くなることがある。

## アーキテクチャ（実際に動いている構成）

```
[スマホ: Space「Wan動画生成アプリ」]
画像を選ぶ + プロンプト・解像度・秒数・fps を設定
│ APIキーは端末内 localStorage から読み、Authorization ヘッダに付ける
│ HTTPS (JSON: 画像は base64) — api.runpod.ai は CORS 許可済み
▼
[RunPod Serverless Endpoint: wan-i2v-5b]
公式 worker-comfyui が ComfyUI ワークフローを実行
│
├─ モデルの重み: Network Volume wan-i2v-models (/runpod-volume/models)
└─ Wan 2.2 TI2V-5B ワークフロー（検証済み wan22_ti2v_5b_api.json）
│
▼
mp4 を base64 でレスポンスに含めて返す（output.images[0].data）
│
▼
[スマホ] デコードして再生・保存
```

ジョブは非同期です。`POST /run` でジョブ ID を受け取り、
`GET /status/<ジョブID>` をポーリングして完了を待ちます。

### アプリ（スマホ側）の責務

- 画像ファイル選択と base64 変換（長辺 1024px に縮小して PNG 化）
- 動作プロンプト / ネガティブプロンプトの入力
- 解像度（832×480 横長 / 480×832 縦長 / 640×640 正方形。送信時は半分に換算）
- 秒数（約2 / 3.4 / 5秒）と fps（24 / 16 / 12）の設定 → フレーム数（4n+1）に換算
- JSON を組み立ててエンドポイントへ送信、状態ポーリング、動画のデコード・再生・保存
- 未成年に関する表現を含むプロンプトの送信前ブロック（簡易キーワードガード）

### 残高が尽きたらどうなるか（公式ドキュメント確認済み）

- 残高 $0 で稼働中のものは止まるが、**Volume のデータはすぐには消えない**
- ただし $0 のまま長く放置すると Volume が終了され、データが復旧できなくなる可能性がある（猶予期間は公式に明言なし）
- Volume が残っているうちに入金すれば、そのまま復活する
- 万一 Volume が消えても、重みを Pod 経由で入れ直せば復旧できる（時間と少しの GPU 代がかかる）
- 自作 Worker 用には、起動時に重みが無ければ自動で落とし直す保険（`download_models.py`）を実装済み。
  ただし公式 worker-comfyui イメージの現行ルートではこのスクリプトは動かないため、
  現行ルートでの復旧は「Pod 経由で入れ直し」が担当する

## 使い方（ユーザー向け）

1. スマホで Space「Wan動画生成アプリ」を開く
2. 初回だけ、設定に RunPod の APIキーを貼る（端末内にのみ保存）
3. 「接続テスト」で疎通を確認
4. 画像を選び、プロンプト・解像度・秒数・fps を決めて「生成する」
5. GPU の空き待ち + 生成で数分〜15分ほど待つ（待ち時間は無料）
6. 完了したらその場で再生、「動画を保存」で端末に保存

## ⚠️ お金についての注意（変わらず重要）

- Serverless はワーカーの**実行時間だけ**秒単位で課金。キュー待ちは無料。
- Volume は**削除するまで月 $1.40** が続く。使わない期間が長くなりそうなら削除も検討。
- 残高が $0 になると生成は止まる。$3 でメール通知が来る設定にしてある。
- 1本の単価感: 480p・約2秒・実行約2分で数セント程度（GPU の空き状況で待ち時間は変動）。
